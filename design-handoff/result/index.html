골격
  • 왼쪽 대화 400px + 오른쪽 화면. 이 도구의 본체는 대화다. E1 부터 같은 자리·같은 마크업을 쓰고, 각 단계의 입력은 응답 말풍선 안 .msg-form 으로 들어간다.
  • 오른쪽 화면은 단계마다 내용만 갈린다 — E1 나오는 것 · P1 4안 · P2 도식 · W1 미리보기와 코드 · D1 관리자 도식 · S1 흐린 미리보기.
  • P2 는 와이어의 목록·도식 두 상태를 하나로 합쳤다. 폭이 모자라 나눴던 것이므로 전환 버튼을 없앴다.
  • S1 은 겹치는 자리를 오른쪽에서 왼쪽 대화 자리로 옮겼다. 결과를 보는 자리를 가리지 않는다.
  • 단계 표시는 상단 앱바 대신 대화 머리 아래 얇은 줄(.steprail)로 상시 노출한다.
테마
  • 아씨드 콘크리트직각 · 검은 굵은 선 · 형광 라임 + 바이올렛
  • 솔라 사막모래 판 · 청회 잉크 · 오아시스 청록 (기본)
  • 이끼와 유자이끼 잉크 · 풀빛 판 · 유자 노랑

html[data-theme] 하나로 갈린다. 색뿐 아니라 라운드·그림자까지 테마가 정한다. 전환은 theme.js 30줄이고 상태는 localStorage 한 칸이다. 후보 8개는 팔레트 페이지에 남겼다.

포팅 메모
  • shell.css 를 design.css 로 갈아끼운다. --bg --surface --border --text --dim --accent --danger --radius 변수명과 기존 클래스명(.field .field-label .opts .opt .card .list .panel-foot .msg .badge)을 그대로 남겼다.
  • 추가한 클래스: .chatshell .chatpane .chat-head .chat-body .chat-foot .steprail .canvas .canvas-head .canvas-body .msg-form .composer .shot .admin .path .drawer .tabs .tab pre.code .eyebrow .token .from-concept.
  • 도식은 이미지가 아니라 .shot 마크업이다. 플래그에 따라 .shot-side 위치와 .item 구성만 바꿔 그린다.
  • 주행동 버튼은 --accent + --on-accent 를 쓴다. 테마마다 글자색이 달라야 해서 짝으로 둔다.
  • .spec 과 .spec-* 는 이 명세 문서용 껍데기다. 앱에는 넣지 않는다.
