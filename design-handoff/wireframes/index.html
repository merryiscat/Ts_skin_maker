티스토리 스킨 생성기 - 화면 기획

사용자가 자기 API 키로 자기 스킨을 만들어 가져가는 정적 웹페이지. 서버 없음, 수익화 없음.

영역

  • E 진입 - 소개, API 제공자 선택, 키 등록, 모델 선택
  • P 프리셋 - 시작점 선택
  • W 작업 - 대화, 미리보기, 검증 상태, 코드 열람
  • D 산출 - 내려받기, 티스토리 설치 안내
  • S 설정 - 키 교체, 모델 변경, 대화 초기화

화면

  • E1 진입 / 키 등록 - 결과물 도식을 먼저 보여주고 키를 받는다. 저장은 기본 꺼짐
    확정 · 4안 보기
  • P1 컨셉 고르기 - 용도와 컨셉을 묻고 그 답으로 만든 컨셉 4안을 제시. 갈리는 것은 레이아웃이 아니라 컨셉
    확정 · 4안 보기 · 4안 파일은 "어떻게 고르게 할까"를 다룬 것이라 확정안과 층위가 다름
  • P2 세부 정하기 - 목록으로 훑고 도식으로 다듬는다. 여기서는 API 를 쓰지 않아 비용이 0
    확정 · 4안 보기
  • W1 작업 화면 - 대화로 고쳐 나간다. 보편 A 확정
    확정 · 4안 보기
  • D1 내려받기 / 설치 안내 - 관리자 화면 도식으로 위치를 짚는다. 파일업로드 탭이 최대 난관
    확정 · 4안 보기
  • S1 설정 - 작업 위에 겹치는 패널. 키 교체만 E1으로 보낸다
    확정 · 4안 보기

흐름

E1 키 등록 - P1 컨셉 고르기 - P2 세부 정하기 - W1 작업 (반복) - D1 내려받기

컨셉을 먼저 정하고 그다음 세부로 내려간다. 사이드바 위치 같은 것을 컨셉보다 먼저 물으면 답할 수 없다.

W1 에서 상단 버튼으로 S1 설정에 들어가고 다시 W1 으로 돌아온다.

기획 규칙

  • 흑백만. 구조는 1px 보더로 표현한다.
  • 이모지 금지. 카피는 짧고 건조하게.
  • 새 화면은 4안을 먼저 만들어 선택을 받는다.
