### 1. OpenAI / Google 모델 단가 채우기 (합의됨, 착수 전)

`webapp/providers.js` 의 `RECOMMENDED.openai` 와 `.google` 이 빈 배열이다.
제공자별로 **최고 성능 3 + 가성비 2, 총 5개**를 골라 모델 ID·단가를 넣는다.

- 단가는 **공식 요금 페이지를 조회해서** 채운다. 추측 금지 —
  `providers.js` 의 규칙: *price 를 모르면 두지 않는다. 틀린 단가를 보여 주는 것보다 "모름"이 낫다*

- 넣고 나면 `webapp/test/providers.test.mjs` 의 "추천 밖 모델은 null" 검사가
  아직 맞는지 확인할 것 (추천에 넣은 모델을 그 검사가 쓰고 있으면 깨진다)

**앤트로픽은 채워져 있다.** 출처는 claude-api 스킬 카탈로그(2026-06-24 캐시)이고
Fable 5 / Opus 5 / Opus 4.8 / Sonnet 5 / Haiku 4.5 다섯 개다.

### 2. 화면 렌더 확인 (E1 외 전부)

브라우저로 눈으로 본 것은 **E1 뿐이다.** 나머지는 테스트만 통과한 상태다.
테스트는 DOM 을 그리지 않으므로(import·서명·이모지·style 태그 금지만 본다)
여백이 틀어졌거나 자리가 어긋난 것은 못 잡는다.

확인이 필요한 것: **P1 · P2 · W1 · D1**, 그리고 **S1 설정 서랍**.
특히 서랍이 격자 첫 칸을 제대로 차지하는지, 오른쪽 캔버스가 흐려진 채 남는지.

P1 부터는 키 확인을 통과해야 들어가지고, 4안 생성은 모델을 실제로 부른다(비용 발생).

## 알고 있는 한계

이건 버그가 아니라 "이렇게 만들기로 한 것"이다. 고치려 들기 전에 이유를 볼 것.

- **`chatModels` 필터는 이름 기반이다.** `webapp/providers.js` 의 `NOT_CHAT` 정규식으로
  음성·이미지·임베딩 모델을 걸러 낸다. 새 종류가 나오면 못 걸린다.
  **빼는 목록**으로 만든 것은 의도다 — 모르는 이름은 남긴다. 반대로 만들면
  새로 나온 대화 모델이 사라져 쓸 수 없게 되고, 그쪽이 더 나쁘다
- **앤트로픽 단가는 캐시된 카탈로그 기준이다.** 가격이 바뀌면 표도 같이 낡는다.
  E1 비용 표는 어림값이라고 화면에 적어 두었다
- **미리보기가 못 잡는 것이 있다.** 렌더러는 티스토리가 본문에 씌우는 래퍼를
  재현하지 않는다. 문단 여백 같은 문제는 실제 블로그에 올려야 드러난다.
  `webapp/harness/pitfalls.js` 가 그 목록이다

## src/ 스킨 쪽 미해결

webapp 과 별개로 손으로 만든 스킨에 남아 있는 것.

- **페이지 기능 미지원.** 독립 고정 문서(페이지)는 `<s_page_rep>` 치환자가 필요한데
  아직 없다. 사용자가 페이지 기능을 쓰게 되면 추가할 것
- **형광펜 방어 CSS 가 주석 상태.** `style.css` 17번 섹션. 실제 글로 에디터가
  뿜는 HTML 을 확인한 뒤 켤 것
- **이미지 지연 로딩 미구현.** 관련 스킨 옵션 변수도 함께 제거된 상태
