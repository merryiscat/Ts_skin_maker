만든 스킨을 티스토리에 올리는 화면. 설치가 두 곳으로 갈라져 있고 한쪽을 빠뜨리면 레이아웃이 통째로 깨진다.

약점

네 안이 갈리는 지점

  • 보편 A - 전체를 펼쳐 놓고 사용자가 순서를 잡는다.
  • 보편 B - 순서를 강제해 빠뜨림을 구조로 막는다.
  • 실험 A - 막히는 원인이 설명이 아니라 위치라고 보고 남의 화면을 그려 짚는다.
  • 실험 B - 한 번에 하나만 보여 판단 자체를 없앤다.

어느 안이든 들어가야 하는 것

  • 설치가 두 곳으로 갈라진다는 사실. skin.html 과 style.css 는 붙여넣기, images 아래는 파일 올리기
  • 파일업로드 탭에서는 기존 파일을 지우고 다시 올려야 한다는 것
  • 그 단계를 빠뜨리면 어떻게 되는지. 화면이 깨진 모습을 미리 알려야 나중에 원인을 찾는다
  • ZIP 은 보관용이고 그것만으로는 설치가 안 된다는 것
  • index.xml 은 스킨을 새로 등록할 때만 필요하다는 것
  • 작업 화면으로 돌아가기. 설치해 보고 더 고치고 싶어질 수 있다

미정

  • 혼합 가능. 보편 B의 체크리스트에 실험 A의 관리자 도식을 각 단계마다 붙이는 식.
  • 설치 후 확인 방법을 줄지. "이렇게 보이면 성공, 이렇게 보이면 파일 올리기를 빠뜨린 것" 같은 대조.
  • 티스토리 관리자 화면이 바뀌었을 때 누가 알아채고 고칠지.
