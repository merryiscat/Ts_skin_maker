실험 B

시도 스냅샷 타임라인

네 안이 갈리는 지점

  • 보편 A - 대화 기록을 남기는 데 무게. 과정이 보인다.
  • 보편 B - 결과물을 크게 보는 데 무게. 판단이 정확해진다.
  • 실험 A - 지시 방법 자체를 바꾼다. 말 대신 클릭으로 대상을 잡는다.
  • 실험 B - 반복의 단위를 대화가 아니라 시도로 본다. 되돌리기가 일급이 된다.

  • 검증 상태 표시 - 통과 / 실패. 실패 시 무엇이 왜 막혔는지

  • 사용한 토큰 표시 - 비용이 사용자 지갑에서 나가므로

미정

  • 혼합 가능. 예를 들어 보편 B의 큰 미리보기에 실험 B의 시도 목록을 붙일 수 있다.
  • 코드 직접 편집 패널을 어디에 둘지는 안 정리를 고른 뒤에 결정한다.
