스킨을 바꾸고 나면 목록 화면은 금방 확인이 되는데 본문은 글을 하나 올려 봐야 안다. 이 글은 그 확인용이다. 문단, 제목, 코드, 인용, 표, 목록을 한 번씩 넣어 두었다.

특히 문단 사이 간격을 본다. 티스토리는 본문을 감싸면서 문단 여백을 없애기 때문에, 스킨이 그걸 되돌려 놓지 않으면 아래 문단들이 전부 한 덩어리로 붙어 보인다. 지금 이 문단과 위 문단 사이가 벌어져 있으면 정상이다.

붙어 보인다면 스킨의 CSS가 덜 올라간 것이다.

## 제목이 잘 나오는가

제목은 본문 안에서 눈에 띄어야 하고, 아래 구분선이 붙는다. 이 문단은 제목 바로 아래 문단이라 위쪽 여백이 제목과 겹치지 않아야 한다.

화면이 넓으면 오른쪽에 목차가 뜬다. 목차는 1500px 이상에서만 나오므로 좁은 화면에서는 안 보이는 것이 정상이다. 스크롤을 내리면 지금 읽는 위치가 목차에서 표시된다.

### 작은 제목

작은 제목은 큰 제목보다 작고 구분선이 없다. 여기까지 나왔다면 제목 계층은 정상이다.

## 코드가 읽히는가

문장 안에 들어가는 `inline code` 는 배경이 옅게 깔린다. 파일 이름이나 `--color-accent` 같은 값을 적을 때 쓴다.

아래는 코드 블록이다. 가로로 넘치지 않고 줄바꿈되어야 하고, 마우스를 올리면 오른쪽 위에 복사 버튼이 나온다.

```css
.article-content p {
  margin-bottom: 0.875em !important;
}

.article-content p:empty {
  min-height: 1.7em;
}
```

긴 줄도 확인한다. 아래 줄은 일부러 길게 썼다.

```javascript
const result = items.filter((item) => item.published && item.category === 'study').map((item) => ({ id: item.id, title: item.title }));
```

## 인용과 목록

> 인용문은 왼쪽에 강조색 세로선이 붙는다. 문단이 여러 줄이어도 간격이 유지되어야 한다.

순서 없는 목록이다.

- 첫 번째 항목
- 두 번째 항목. 조금 길게 써서 줄이 넘어갈 때 들여쓰기가 유지되는지 본다
- 세 번째 항목

순서 있는 목록이다.

1. 스킨 편집에서 HTML 붙여넣기
2. CSS 붙여넣기
3. 파일업로드 탭에서 script.js 올리기
4. 저장하고 새로고침
